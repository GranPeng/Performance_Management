## 2. 抽查方法

抽取 3 名员工，按照 Sheet2 的目标值/实际值及 Sheet3 的 V04 原文逐项手工复算：

1. 达成率 = 实际值 ÷ 目标值（适用时）。
2. 按 Sheet3 同行 V04 评分标准确定自动分；次数/扣分制按原文直接判分。
3. 加权分 = 最终得分 × 权重；月度总分为同员工、同期间各行加权分之和。
4. 将手算结果和 Sheet3 结果 ID 对应行比较。

说明：定性/客服奖惩指标缺少负责人 `Manual_Score` 时，D-009.3 要求不得伪造或填 0。V02 在“人工分/最终得分/加权得分”显示为“待人工分”。同期 `Monthly_Total` 列保留 Base 当前公式输出，不能被误读为人工评分完成后的最终审批值。
