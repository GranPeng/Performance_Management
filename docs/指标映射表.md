## 映射原则
- 以 T1 的 `data/output/绩效框架结构化规则.json` 中“达成率/进度型”指标为完整锚点；不改变KPI或预算字段的业务含义。
- “候选映射”不等于可直接用于计算：若源名称、退货/签收范围、归因颗粒度或时间窗口未被源文件明确支持，必须保留为待确认。

## 待业务确认事项
1. V60“主营业务收入”是否等同于绩效中的“退货后营收（GSV）”；如不等同，需提供退货后GSV的权威预算来源与渠道映射。
2. 签收ROI的预算目标在何处维护；不得以广告投流费、销售费用率等字段自行反推。
3. V60渠道与岗位“所负责渠道”的关系表，以及项目组/个人/素材90天归因的数据来源。
